# Sanitized shadow-decision sample

The JSONL files contain only locally recorded `ENTER` decisions from July 12–13, 2026.
The summary preserves counts for every decision type and hashes of the original complete
logs. Local paths, session identifiers, full feature vectors, and private raw state were
removed.

Classification: **prospective shadow-system operation; not a performance score**. The
records are not independently timestamped and do not establish fills, outcomes, PnL, or
a trading edge.
