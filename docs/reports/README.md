# Retained historical reports

This directory contains a small historical subset for implementation context. The reports
depend on private data and can contain superseded intermediate conclusions. They are not
publication evidence and do not override the
[canonical claim register](../PUBLICATION_CLAIMS.md).

Retained groups:

- Oracle/proxy diagnostics: `chainlink_*`, `synthetic_chainlink_*`, and
  `delta_to_strike_chainlink_error_analysis.*`.
- Leakage and quality audits: `trojan_horse_audit_report.md`, `quant_audit_*`.
- Machine-readable audit outputs and schema contracts.
- `RECORDER_FULL_AUDIT_DESCRIPTION.txt` for recorder-contract context.

Private-data-only model reports, superseded OOS narratives, and the pre-audit profitable
strategy summaries were removed from the public edition because they added unsupported
claims without reproducible inputs.
